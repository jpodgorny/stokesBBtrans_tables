This repository will contain the disc-atmosphere rest-frame transmission X-ray spectro-polarimetric tables created with the Monte Carlo code STOKES (Goosmann & Gaskell, 2007), originally created for usage inside the KYN model suite. The atmosphere has a finite optical depth.

* [stokesBBtrans-v1.0.fits](https://owncloud.asu.cas.cz/index.php/s/wrlUIOwLd6fI8YU)
→ originally called "goosmann.fits" tables with full ionization of the slab and Thomson scattering, as in Sunyaev & Titarchuk (1985);

* The variants (versions 2.0+) for partially ionized slab atmospheres (coupled to CLOUDY or TITAN photo-ionization codes) and Compton scattering are not yet publicly available.

A proper description and links to all STOKESBBTRANS tables is a work in progress.
